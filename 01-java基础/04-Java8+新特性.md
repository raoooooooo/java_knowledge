# 04 - Java 8+ 新特性

## 核心概念

- Lambda 表达式
- 函数式接口
- Stream API
- Optional 类
- 默认方法与静态方法
- 方法引用
- 新的日期时间 API（LocalDate/LocalDateTime）
- CompletableFuture
- 接口的私有方法（Java 9+）
- var 类型推断（Java 10+）
- Switch 表达式（Java 12+）
- Text Blocks（Java 13+）
- Record 类型（Java 14+）
