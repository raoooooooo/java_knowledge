# 二叉树

> 📌 **一句话理解**：二叉树是每个节点最多有两个子节点（左子节点、右子节点）的树形结构，是算法面试中最高频的数据结构之一。核心考点：遍历方式、特殊二叉树（BST/AVL/红黑树/堆）、经典题型（最大深度、最近公共祖先、路径和等）。

---

## 一、基础概念

### 1.1 树的基本术语

| 术语 | 含义 |
|------|------|
| **节点 (Node)** | 树的基本单元，包含数据和指向子节点的指针 |
| **根节点 (Root)** | 树的顶层节点，没有父节点 |
| **叶节点 (Leaf)** | 没有子节点的节点（度为 0） |
| **父节点 / 子节点** | 有子节点的是父节点，被指向的是子节点 |
| **兄弟节点 (Sibling)** | 同一个父节点的子节点 |
| **节点的度** | 一个节点含有的子节点个数 |
| **树的度** | 树中所有节点的度的最大值 |
| **深度 (Depth)** | 从根节点到该节点的路径上的节点数（或边数，看定义） |
| **高度 (Height)** | 从该节点到最远叶节点的路径上的节点数（或边数） |
| **层级 (Level)** | 根节点在第 1 层（或第 0 层，看定义） |
| **森林 (Forest)** | 多棵互不相交的树的集合 |

> ⚠️ 注意：深度和高度的定义有两种——「节点数」和「边数」，面试时最好说清楚你用的是哪种。LeetCode 一般用「节点数」定义（叶子高度为 1）。

### 1.2 二叉树的定义

二叉树是每个节点**最多有两个子节点**（左子节点和右子节点）的树，子节点有左右之分，次序不能颠倒。

**二叉树节点定义（Java）：**
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}
```

### 1.3 二叉树的性质

1. **第 i 层最多有 2^(i-1) 个节点**（根在第 1 层）
2. **深度为 h 的二叉树最多有 2^h - 1 个节点**（满二叉树）
3. **任意二叉树，叶节点数 n0，度为 2 的节点数 n2，则 n0 = n2 + 1**
   - 推导：总结点数 n = n0 + n1 + n2，总边数 = n - 1 = n1 + 2*n2，联立得 n0 = n2 + 1
4. **n 个节点的完全二叉树的深度为 ⌊log2(n)⌋ + 1**

## 二、二叉树的分类

### 2.1 满二叉树 (Full Binary Tree)

除了叶节点外，所有节点都有两个子节点，且叶节点都在最后一层。

```
       1
     /   \
    2     3
   / \   / \
  4   5 6   7
```

- 深度为 h 的满二叉树有 2^h - 1 个节点
- 叶子节点数 = 2^(h-1)

### 2.2 完全二叉树 (Complete Binary Tree)

除了最后一层外，其他层的节点数都达到最大值，且最后一层的节点都**连续集中在最左边**。

```
       1
     /   \
    2     3
   / \   /
  4   5 6      ← 最后一层从左到右连续，不能有"缺口"
```

- 满二叉树是特殊的完全二叉树
- **堆就是一种完全二叉树**
- n 个节点的完全二叉树深度为 ⌊log2(n)⌋ + 1
- **重要性质**：对于下标为 i 的节点（数组下标从 0 开始）：
  - 左子节点：2i + 1
  - 右子节点：2i + 2
  - 父节点：(i - 1) / 2

### 2.3 二叉搜索树 (Binary Search Tree, BST)

也叫二叉排序树。是一种有序的二叉树：
- **左子树所有节点的值 < 根节点的值**
- **右子树所有节点的值 > 根节点的值**
- 左、右子树也分别是二叉搜索树

```
       8
     /   \
    3     10
   / \      \
  1   6      14
     / \    /
    4   7  13
```

**BST 的性质：**
- 中序遍历结果是**升序序列**（BST 最重要的性质，很多题都靠这个解）
- 查找、插入、删除的平均时间复杂度：O(log n)
- 最坏时间复杂度：O(n)（退化成链表）

**BST 插入 / 查找 / 删除：**

- **查找**：从根开始，比当前小走左，比当前大走右，等于则找到
- **插入**：类似查找，找到空位置插入新节点
- **删除**（三种情况）：
  1. 待删除节点是叶子 → 直接删除
  2. 待删除节点只有一个子节点 → 用子节点替换
  3. 待删除节点有两个子节点 → 用**右子树的最小值**（后继）或**左子树的最大值**（前驱）替换，然后删除那个后继/前驱节点

### 2.4 平衡二叉搜索树 (AVL Tree)

BST 的问题：如果插入数据有序，会退化成链表，O(n)。

AVL 树是一种**自平衡**的 BST，满足：
- 每个节点的**左右子树高度差（平衡因子）不超过 1**
- 查找、插入、删除都是 O(log n)，包括最坏情况

**平衡因子 (Balance Factor)**：左子树高度 - 右子树高度（或反过来），范围 {-1, 0, 1}

**四种旋转（自平衡的核心）：**

| 失衡情况 | 旋转方式 | 示意图 |
|---------|---------|--------|
| 左左（LL） | 右旋转 | 在失衡节点做右旋 |
| 右右（RR） | 左旋转 | 在失衡节点做左旋 |
| 左右（LR） | 先左旋后右旋 | 先在左孩子左旋，再在失衡节点右旋 |
| 右左（RL） | 先右旋后左旋 | 先在右孩子右旋，再在失衡节点左旋 |

**LL 失衡与右旋转示例：**
```
    30（失衡）               20
   /                       /  \
  20       右旋 →         10   30
 /
10
```

> ⚠️ 易错点：AVL 树面试考得不算多，但**平衡因子、四种旋转方式、时间复杂度**是基础题要知道。实际工程中用得更多的是红黑树（AVL 太严格，插入删除旋转频繁）。

### 2.5 红黑树 (Red-Black Tree)

红黑树也是一种自平衡 BST，但它不要求"高度差不超过 1"，而是用**颜色规则**来保证近似平衡（最长路径不超过最短路径的 2 倍）。

**五条性质（必须背）：**
1. 每个节点要么是红色，要么是黑色
2. **根节点是黑色**
3. **每个叶节点（NIL 节点）是黑色**（空节点也是黑色）
4. **红色节点的两个子节点都是黑色**（不能有两个连续的红色节点）
5. **从任意节点到其每个叶节点的所有路径，包含的黑色节点数量相同**（黑高相同）

**为什么这五条能保证平衡？**
- 性质 4：不能有连续红节点 → 红色节点不能相邻
- 性质 5：每条路径黑色节点数相同
- → 最长路径（红黑交替）不会超过最短路径（全黑）的 2 倍
- → 树的高度是 O(log n)，近似平衡

```
        13（黑）
       /    \
     8（红） 17（红）
     / \    /    \
   1（黑）11（黑）15（黑）25（黑）
               \
               17（红） ← NIL（黑）
```

**红黑树 vs AVL 树：**

| 特性 | AVL 树 | 红黑树 |
|------|--------|--------|
| 平衡严格度 | 严格（高度差≤1） | 近似平衡（最长≤最短2倍） |
| 查找速度 | 更快（更平衡） | 稍慢（但也是 O(log n)） |
| 插入删除 | 旋转多（严格维护平衡） | 旋转少（颜色调整为主） |
| 适用场景 | 读多写少 | 读写均衡（实际更常用） |
| 实际应用 | 少 | 多（Java TreeMap、HashMap、C++ map 等） |

> 💡 **面试常考**：红黑树五条性质、和 AVL 的区别、HashMap 中红黑树的使用（链表长度 ≥ 8 且数组长度 ≥ 64 时树化）。

### 2.6 堆 (Heap)

堆是一种**完全二叉树**，分为大顶堆和小顶堆。

- **大顶堆（大根堆）**：每个节点的值 ≥ 其左右子节点的值，根节点最大
- **小顶堆（小根堆）**：每个节点的值 ≤ 其左右子节点的值，根节点最小

**大顶堆示例：**
```
        10
       /  \
      7    9
     / \  /
    5  6 8
```

**堆的存储（数组）：**
完全二叉树的特性 → 可以用数组存，不需要指针。
下标为 i 的节点（0 开始）：
- 左孩子：2i + 1
- 右孩子：2i + 2
- 父节点：(i - 1) / 2

**堆的核心操作：**

1. **上浮 (sift up / heapify up)**：插入时用。新元素加到末尾，然后和父节点比较，不符合堆性质就交换，直到符合或到根
   - 时间复杂度：O(log n)

2. **下沉 (sift down / heapify down)**：删除堆顶时用。把最后一个元素移到堆顶，然后和较大的（大顶堆）子节点比较交换，直到符合或到叶子
   - 时间复杂度：O(log n)

3. **建堆 (heapify)**：把一个无序数组变成堆
   - 从最后一个非叶节点开始，向前逐个做下沉操作
   - 时间复杂度：**O(n)**（不是 O(n log n)！因为叶子节点不需要下沉，越靠上的节点下沉深度越小）
   - 推导：n/2 个叶子（不用下沉）+ n/4 个下沉 1 层 + n/8 个下沉 2 层 + ... = n/4 + 2n/8 + 3n/16 + ... = n

4. **堆排序**：
   - 建大顶堆 → O(n)
   - 不断把堆顶和末尾交换，然后堆大小减 1，堆顶下沉 → O(n log n)
   - 总时间复杂度：O(n log n)
   - 空间复杂度：O(1)（原地排序）
   - 不稳定

**Java 中的堆：**
- `PriorityQueue`（默认小顶堆，大顶堆需要传比较器）
  ```java
  // 默认小顶堆
  PriorityQueue<Integer> minHeap = new PriorityQueue<>();
  // 大顶堆
  PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
  ```

**堆的常见应用：**
- Top K 问题（大顶堆求最小 K 个，小顶堆求最大 K 个）
- 堆排序
- 优先队列
- 中位数问题（大顶堆 + 小顶堆）
- 多路归并排序

### 2.7 哈夫曼树 (Huffman Tree)

带权路径长度（WPL）最小的二叉树，也叫最优二叉树。

**构建方法：**
1. 把每个权值作为一个节点，构成森林
2. 每次选两个权值最小的节点合并（新建一个节点，权值为两者之和）
3. 新节点加入森林，重复步骤 2 直到只剩一棵树

**哈夫曼编码**：哈夫曼树的应用，左 0 右 1，频率高的字符编码短，频率低的编码长，实现数据压缩。

## 三、二叉树的遍历（核心中的核心）

二叉树遍历是所有二叉树题的基础，必须熟练掌握递归和迭代两种写法。

### 3.1 四种遍历方式

以这棵树为例：
```
    1
   / \
  2   3
 / \
4   5
```

| 遍历方式 | 顺序 | 结果 | 说明 |
|---------|------|------|------|
| **前序遍历** | 根 → 左 → 右 | 1, 2, 4, 5, 3 | 先访问根，再左子树，再右子树 |
| **中序遍历** | 左 → 根 → 右 | 4, 2, 5, 1, 3 | 先左，再根，再右。**BST 中序是升序** |
| **后序遍历** | 左 → 右 → 根 | 4, 5, 2, 3, 1 | 先左，再右，再根。删除树、求高度用 |
| **层序遍历** | 逐层从左到右 | 1, 2, 3, 4, 5 | BFS，用队列实现 |

### 3.2 递归遍历（必会）

**前序遍历：**
```java
public void preorder(TreeNode root) {
    if (root == null) return;
    System.out.println(root.val); // 根
    preorder(root.left);          // 左
    preorder(root.right);         // 右
}
```

**中序遍历：**
```java
public void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);           // 左
    System.out.println(root.val); // 根
    inorder(root.right);          // 右
}
```

**后序遍历：**
```java
public void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);         // 左
    postorder(root.right);        // 右
    System.out.println(root.val); // 根
}
```

> ⚠️ 递归遍历时间复杂度 O(n)，空间复杂度 O(h)（h 为树高，递归栈）。

### 3.3 迭代遍历（面试高频）

递归写起来简单，但面试经常要求写**迭代版本**（用栈模拟递归）。

**前序遍历（迭代，栈）：**
```java
// 思路：用栈，先压右再压左，这样出栈顺序是左->右
public List<Integer> preorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);              // 根
        if (node.right != null) stack.push(node.right); // 先压右（后出）
        if (node.left != null) stack.push(node.left);   // 后压左（先出）
    }
    return res;
}
```

**中序遍历（迭代，栈）：**
```java
// 思路：一直往左走，边走边压栈；走到头了弹出，访问，然后转右
public List<Integer> inorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;  // 一直往左走
        }
        cur = stack.pop();
        res.add(cur.val);    // 根
        cur = cur.right;     // 转右
    }
    return res;
}
```

**后序遍历（迭代，栈）：**
```java
// 方法一：前序翻转法
// 前序是 根左右 → 改成 根右左 → 翻转就是 左右根（后序）
public List<Integer> postorderIterative(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.left != null) stack.push(node.left);  // 先左
        if (node.right != null) stack.push(node.right); // 后右
    }
    Collections.reverse(res); // 翻转得到后序
    return res;
}

// 方法二：用 prev 指针记录上一个访问的节点，判断右子树是否已访问
public List<Integer> postorderIterative2(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root, prev = null;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.peek();
        if (cur.right == null || cur.right == prev) {
            // 右子树为空或已经访问过，可以访问根
            res.add(cur.val);
            prev = cur;
            stack.pop();
            cur = null;
        } else {
            // 右子树还没访问，先访问右子树
            cur = cur.right;
        }
    }
    return res;
}
```

**层序遍历（BFS，队列）：**
```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();       // 当前层节点数
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 3.4 遍历的应用场景

| 遍历方式 | 典型应用 |
|---------|---------|
| 前序遍历 | 复制树、序列化、打印目录结构 |
| 中序遍历 | BST 的升序序列（最重要的应用！）、验证BST |
| 后序遍历 | 删除树（先删子节点再删根）、求树的高度、后序表达式 |
| 层序遍历 | 树的宽度、按层打印、二叉树的右视图、BFS相关 |

## 四、经典题型（面试必刷）

### 4.1 树的高度/深度

**LeetCode 104. 二叉树的最大深度**
```java
// 后序遍历：左右子树最大高度 + 1
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int left = maxDepth(root.left);
    int right = maxDepth(root.right);
    return Math.max(left, right) + 1;
}
```

**LeetCode 110. 平衡二叉树**
```java
// 思路：后序遍历，一边求高度一边判断是否平衡
// 用 -1 表示不平衡，避免重复计算
public boolean isBalanced(TreeNode root) {
    return height(root) != -1;
}
private int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    if (left == -1) return -1;
    int right = height(node.right);
    if (right == -1) return -1;
    if (Math.abs(left - right) > 1) return -1;
    return Math.max(left, right) + 1;
}
```

### 4.2 对称/相同的树

**LeetCode 100. 相同的树**
```java
public boolean isSameTree(TreeNode p, TreeNode q) {
    if (p == null && q == null) return true;
    if (p == null || q == null) return false;
    if (p.val != q.val) return false;
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
}
```

**LeetCode 101. 对称二叉树**
```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return helper(root.left, root.right);
}
private boolean helper(TreeNode a, TreeNode b) {
    if (a == null && b == null) return true;
    if (a == null || b == null) return false;
    if (a.val != b.val) return false;
    // 注意：左的左 vs 右的右，左的右 vs 右的左
    return helper(a.left, b.right) && helper(a.right, b.left);
}
```

### 4.3 翻转二叉树

**LeetCode 226. 翻转二叉树（Homebrew 作者那道题）**
```java
// 前序遍历：交换左右子节点，再递归翻转左右
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    // 交换
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;
    // 递归
    invertTree(root.left);
    invertTree(root.right);
    return root;
}
```

### 4.4 最近公共祖先 (LCA)

**LeetCode 236. 二叉树的最近公共祖先**
```java
// 后序遍历思路：
// 如果 p 和 q 分别在左右子树，当前节点就是 LCA
// 如果只有一边有，返回那边的结果
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root; // 两边都有 → 就是LCA
    return left != null ? left : right; // 只有一边有 → 返回那边
}
```

**LeetCode 235. 二叉搜索树的最近公共祖先**
```java
// BST 的 LCA 更简单：利用 BST 性质
// 如果都比根小 → 去左边；都比根大 → 去右边；一左一右 → 就是根
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    while (root != null) {
        if (p.val < root.val && q.val < root.val) root = root.left;
        else if (p.val > root.val && q.val > root.val) root = root.right;
        else return root;
    }
    return null;
}
```

```java
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), res);
    return res;
}
private void dfs(TreeNode node, int target, List<Integer> path, List<List<Integer>> res) {
    if (node == null) return;
    path.add(node.val);
    if (node.left == null && node.right == null && node.val == target) {
        res.add(new ArrayList<>(path));
    }
    dfs(node.left, target - node.val, path, res);
    dfs(node.right, target - node.val, path, res);
    path.remove(path.size() - 1); // 回溯
}
```

```java
        node.right = des(q);

    }
```

### 4.7 验证二叉搜索树

**LeetCode 98. 验证二叉搜索树**
```java
// 方法一：递归，带上界下界
public boolean isValidBST(TreeNode root) {
    return helper(root, null, null);
}
private boolean helper(TreeNode node, Integer min, Integer max) {
    if (node == null) return true;
    if (min != null && node.val <= min) return false;
    if (max != null && node.val >= max) return false;
    return helper(node.left, min, node.val) 
        && helper(node.right, node.val, max);
}

// 方法二：中序遍历，应该是升序的
public boolean isValidBST2(TreeNode root) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root, prev = null;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        if (prev != null && cur.val <= prev.val) return false;
        prev = cur;
        cur = cur.right;
    }
    return true;
}
```

```java
// 层序遍历，每层最后一个节点
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (i == size - 1) res.add(node.val); // 每层最后一个
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return res;
}
```

**LeetCode 103. 二叉树的锯齿形层序遍历（之字形）**
```java
public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    boolean leftToRight = true;
    while (!queue.isEmpty()) {
        int size = queue.size();
        LinkedList<Integer> level = new LinkedList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (leftToRight) {
                level.addLast(node.val);
            } else {
                level.addFirst(node.val); // 反向插入
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
        leftToRight = !leftToRight;
    }
    return res;
}
```

### 4.9 完全二叉树的节点数

**LeetCode 222. 完全二叉树的节点个数**
```java
// 方法一：普通遍历 O(n)，但没有利用完全二叉树性质
// 方法二：利用完全二叉树性质，时间复杂度 O(log n * log n)
public int countNodes(TreeNode root) {
    if (root == null) return 0;
    int leftHeight = getHeight(root.left);
    int rightHeight = getHeight(root.right);
    if (leftHeight == rightHeight) {
        // 左子树是满二叉树，左子树 + 根 + 递归右子树
        return (1 << leftHeight) + countNodes(root.right);
    } else {
        // 右子树是满二叉树，递归左子树 + 根 + 右子树
        return countNodes(root.left) + (1 << rightHeight);
    }
}
private int getHeight(TreeNode node) {
    int h = 0;
    while (node != null) {
        h++;
        node = node.left; // 完全二叉树沿左走就能得到高度
    }
    return h;
}
```

### 4.10 二叉树的直径

**LeetCode 543. 二叉树的直径**
```java
// 直径 = 左子树高度 + 右子树高度（边数）
// 后序遍历，顺便更新最大直径
int maxDiameter = 0;
public int diameterOfBinaryTree(TreeNode root) {
    depth(root);
    return maxDiameter;
}
private int depth(TreeNode node) {
    if (node == null) return 0;
    int left = depth(node.left);
    int right = depth(node.right);
    maxDiameter = Math.max(maxDiameter, left + right); // 更新直径
    return Math.max(left, right) + 1;
}
```

### 4.11 构建二叉树

**LeetCode 105. 从前序与中序遍历序列构造二叉树**
```java
// 思路：前序第一个是根，在中序中找到根的位置
// 左边是左子树，右边是右子树，递归构建
public TreeNode buildTree(int[] preorder, int[] inorder) {
    return build(preorder, 0, preorder.length - 1, 
                 inorder, 0, inorder.length - 1);
}
private TreeNode build(int[] pre, int preL, int preR, 
                       int[] in, int inL, int inR) {
    if (preL > preR) return null;
    int rootVal = pre[preL];
    TreeNode root = new TreeNode(rootVal);
    // 在中序中找根的位置
    int idx = inL;
    while (in[idx] != rootVal) idx++;
    int leftSize = idx - inL;
    root.left = build(pre, preL + 1, preL + leftSize, in, inL, idx - 1);
    root.right = build(pre, preL + leftSize + 1, preR, in, idx + 1, inR);
    return root;
}
```

## 五、核心解题技巧总结

### 5.1 二叉树题通用思路

做二叉树题，先想三件事：
1. **用什么遍历方式？**（前/中/后/层序）
2. **递归函数返回什么？**（高度、是否平衡、节点、路径和等）
3. **终止条件是什么？**（节点为空、叶子节点、找到目标等）

### 5.2 遍历选择口诀

| 场景 | 推荐遍历 | 原因 |
|------|---------|------|
| 需要先处理根再处理子树 | 前序 | 根先访问 |
| BST 相关、需要有序性 | 中序 | BST 中序是升序 |
| 需要知道子树结果才能处理根 | 后序 | 高度、直径、平衡判断、LCA |
| 按层处理、宽度、最左/最右 | 层序(BFS) | 逐层遍历 |

### 5.3 递归模板

```java
返回值 dfs(TreeNode root, 参数列表) {
    // 终止条件
    if (root == null) return 默认值;
    
    // 前序位置（处理根）
    ...
    
    // 递归左右
    左结果 = dfs(root.left, 参数);
    右结果 = dfs(root.right, 参数);
    
    // 后序位置（结合左右结果处理根）
    当前结果 = 组合(左结果, 右结果);
    
    return 当前结果;
}
```

### 5.4 时间复杂度

- 遍历类：O(n)（每个节点访问一次）
- BST 查找/插入/删除：平均 O(log n)，最坏 O(n)
- 平衡树 (AVL/红黑树)：O(log n)
- 空间复杂度：递归栈 O(h)，h 为树高。平衡树 O(log n)，链化树 O(n)
