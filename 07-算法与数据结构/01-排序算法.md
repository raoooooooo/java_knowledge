# 排序算法

> 📌 **一句话理解**：排序是算法面试的基础中的基础。必须掌握十大排序的思想、时间/空间复杂度、稳定性，以及快排、归并、堆排序这三大 O(n log n) 排序的手撕代码。

---

## 一、排序算法总览

### 1.1 十大排序分类

```
排序算法
├─ 比较类排序（O(n log n) 及以上）
│  ├─ 交换排序
│  │  ├─ 冒泡排序 (Bubble Sort)       O(n²)
│  │  └─ 快速排序 (Quick Sort)        O(n log n)
│  ├─ 插入排序
│  │  ├─ 简单插入排序 (Insertion Sort)  O(n²)
│  │  └─ 希尔排序 (Shell Sort)         O(n^1.3)
│  ├─ 选择排序
│  │  ├─ 简单选择排序 (Selection Sort)  O(n²)
│  │  └─ 堆排序 (Heap Sort)            O(n log n)
│  └─ 归并排序 (Merge Sort)            O(n log n)
│     ├─ 二路归并
│     └─ 多路归并
│
└─ 非比较类排序（线性时间，对数据有要求）
   ├─ 计数排序 (Counting Sort)   O(n+k)
   ├─ 桶排序 (Bucket Sort)       O(n+k)
   └─ 基数排序 (Radix Sort)      O(n×k)
```

### 1.2 复杂度与稳定性对比（必背）

| 排序算法 | 平均时间 | 最好时间 | 最坏时间 | 空间 | 稳定性 | 排序方式 |
|---------|---------|---------|---------|------|--------|---------|
| 冒泡排序 | O(n²) | O(n) | O(n²) | O(1) | ✅ 稳定 | 比较 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 | 比较 |
| 插入排序 | O(n²) | O(n) | O(n²) | O(1) | ✅ 稳定 | 比较 |
| 希尔排序 | O(n^1.3) | O(n) | O(n²) | O(1) | ❌ 不稳定 | 比较 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 | 比较 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ 稳定 | 比较 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 | 比较 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(k) | ✅ 稳定 | 非比较 |
| 桶排序 | O(n+k) | O(n+k) | O(n²) | O(n+k) | ✅ 稳定 | 非比较 |
| 基数排序 | O(n×k) | O(n×k) | O(n×k) | O(n+k) | ✅ 稳定 | 非比较 |

**稳定性定义**：如果排序后，两个值相等的元素**相对顺序不变**，就是稳定排序。
- 例：数组 `[(2, A), (1, B), (2, C)]` 按值排序
  - 稳定排序结果：`(1, B), (2, A), (2, C)`（两个 2 的相对顺序没变）
  - 不稳定排序结果：`(1, B), (2, C), (2, A)`（可能变了）

**什么时候需要稳定性？**
- 业务上有"先按 A 排序，再按 B 排序"的复合排序需求时
- 比如先按价格排序，价格相同的按销量排序——第一次按销量排（稳定），第二次按价格排（稳定），价格相同的元素保留了销量排序的相对顺序

## 二、O(n²) 基础排序

### 2.1 冒泡排序 (Bubble Sort)

**思想**：每轮把最大的元素"冒泡"到最后。相邻两两比较，大的往后交换。

```
初始：     6  2  8  1  4
第1轮：    2  6  1  4  8   ← 8 冒泡到最后
第2轮：    2  1  4  6  8   ← 6 冒泡到倒数第二
第3轮：    1  2  4  6  8   ← 4 到位
第4轮：    1  2  4  6  8   ← 2 到位，完成
```

**代码：**
```java
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false; // 优化：某轮没交换说明已有序
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
                swapped = true;
            }
        }
        if (!swapped) break; // 没有交换，提前结束
    }
}
```

**特点：**
- 最容易理解的排序
- 加了 swapped 优化后，最好情况 O(n)（已有序）
- 稳定排序：相等的两个元素不会交换，相对位置不变

### 2.2 选择排序 (Selection Sort)

**思想**：每轮从未排序部分选最小的，放到已排序部分的末尾。

```
初始：    6  2  8  1  4
第1轮：   1  2  8  6  4   ← 找到最小的 1，和第一个交换
第2轮：   1  2  8  6  4   ← 找到最小的 2（已经在位置）
第3轮：   1  2  4  6  8   ← 找到最小的 4，和第三个交换
第4轮：   1  2  4  6  8   ← 找到最小的 6，到位
```

**代码：**
```java
public void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        swap(arr, i, minIdx);
    }
}
```

**特点：**
- 思路简单，但无论什么数据都是 O(n²)
- **不稳定**：比如 `5 8 5 2`，第一个 5 和 2 交换后，两个 5 的相对顺序变了
- 交换次数少（最多 n-1 次），在"交换成本很高"的场景有优势

### 2.3 插入排序 (Insertion Sort)

**思想**：把数组分成已排序和未排序两部分，每次从未排序部分取第一个，插入到已排序部分的合适位置。

```
初始：    [6]  2  8  1  4   ← 第一个元素是已排序部分
第1轮：   [2  6] 8  1  4   ← 把 2 插入到 [6] 中
第2轮：   [2  6  8] 1  4   ← 把 8 插入到 [2,6] 中
第3轮：   [1  2  6  8] 4   ← 把 1 插入到最前面
第4轮：   [1  2  4  6  8]   ← 把 4 插入到 2 和 6 之间
```

**代码：**
```java
public void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
        int cur = arr[i]; // 待插入元素
        int j = i - 1;
        // 已排序部分从后往前找，比 cur 大的往后挪
        while (j >= 0 && arr[j] > cur) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = cur; // 插入
    }
}
```

**特点：**
- 稳定排序
- 最好情况 O(n)（数组已有序，每个元素只比较一次）
- **小规模数据或基本有序时非常快**（常数因子小）
- 很多高级排序在数据量小时会切换到插入排序（如快排的小数据优化、TimSort）

### 2.4 希尔排序 (Shell Sort)

**思想**：插入排序的改进版。先按某个**增量 gap** 分组，每组内做插入排序；逐渐缩小 gap，直到 gap=1（就是普通插入排序）。

因为 gap 大的时候每组元素少，排序快；gap 小的时候数组已经基本有序，插入排序也快。

```
初始：        8  9  1  7  2  3  5  4  6  0

gap = 5：    分组：(8,3)(9,5)(1,4)(7,6)(2,0)
             每组插入排序后：3  5  1  6  0  8  9  4  7  2

gap = 2：    分组：(3,1,0,9,7)(5,6,8,4,2)
             每组插入排序后：0  2  1  4  3  5  7  6  9  8

gap = 1：    普通插入排序 → 有序
```

**代码：**
```java
public void shellSort(int[] arr) {
    int n = arr.length;
    for (int gap = n / 2; gap > 0; gap /= 2) { // gap 初始为 n/2，每次减半
        for (int i = gap; i < n; i++) {
            int cur = arr[i];
            int j = i - gap;
            while (j >= 0 && arr[j] > cur) {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = cur;
        }
    }
}
```

**特点：**
- 第一个突破 O(n²) 的排序
- 时间复杂度和 gap 的选择有关，平均约 O(n^1.3)
- **不稳定**：分组插入时相同值的元素可能被分到不同组，相对顺序改变
- 增量序列的选择有讲究（Hibbard 序列、Sedgewick 序列等），不是只有 n/2

## 三、O(n log n) 高级排序（手撕重点）

### 3.1 快速排序 (Quick Sort) — 面试最高频

**思想**：选一个基准（pivot），把数组分成两部分——小于 pivot 的在左边，大于 pivot 的在右边；然后对左右两部分递归排序。

**核心步骤：**
1. 选基准（pivot）
2. **分区（partition）**：把小于 pivot 的放左边，大于的放右边，pivot 放到中间
3. 递归：左右两部分分别快排

**分区过程示意（Hoare 分区法）：**
```
数组：  6  2  8  1  4  3  7  5
pivot = 5（选最后一个）

i=0           j  ← 左右指针
    ↓           ↓
    6  2  8  1  4  3  7  5
    ↑                       ↑
   low                     high

左指针找大于 pivot 的，右指针找小于 pivot 的，交换
...
最终 pivot 放到正确位置，左边都<5，右边都>5
```

**代码（经典写法，pivot 选最右，双指针分区）：**
```java
public void quickSort(int[] arr) {
    quickSort(arr, 0, arr.length - 1);
}
private void quickSort(int[] arr, int low, int high) {
    if (low >= high) return;
    int pivotIndex = partition(arr, low, high);
    quickSort(arr, low, pivotIndex - 1);  // 左半部分
    quickSort(arr, pivotIndex + 1, high); // 右半部分
}
// 分区函数：返回 pivot 的最终位置
private int partition(int[] arr, int low, int high) {
    int pivot = arr[high]; // 选最后一个作为 pivot
    int i = low;           // i 指向"小于 pivot 区域"的下一个位置
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            swap(arr, i, j);
            i++;
        }
    }
    swap(arr, i, high); // pivot 放到正确位置
    return i;
}
private void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
```

**快排优化手段：**

| 优化点 | 做法 | 解决什么问题 |
|--------|------|-------------|
| **三数取中法** | 从 low/mid/high 中选中间值当 pivot | 避免数组已有序时退化为 O(n²) |
| **随机法** | 随机选一个元素当 pivot | 同上，避免最坏情况 |
| **小数组用插入排序** | 当子数组长度 < 阈值（如 10~20）时用插入排序 | 小数组插入排序更快（常数因子小） |
| **尾递归优化** | 只递归短的那一边，长的那边用循环 | 减少递归深度，避免栈溢出 |
| **三路快排** | 把数组分成 < pivot / = pivot / > pivot 三部分 | 有大量重复元素时效率极高 |

**三路快排（荷兰国旗问题思路）：**
```java
public void quickSort3Way(int[] arr, int low, int high) {
    if (low >= high) return;
    int pivot = arr[low + (int)(Math.random() * (high - low + 1))];
    int lt = low, gt = high, i = low;
    // [low, lt-1] < pivot
    // [lt, gt]   = pivot
    // [gt+1, high] > pivot
    while (i <= gt) {
        if (arr[i] < pivot) {
            swap(arr, i, lt);
            lt++;
            i++;
        } else if (arr[i] > pivot) {
            swap(arr, i, gt);
            gt--;
        } else {
            i++;
        }
    }
    quickSort3Way(arr, low, lt - 1);
    quickSort3Way(arr, gt + 1, high);
}
```

**复杂度分析：**
- 平均：O(n log n) — 每次分区分成两个差不多大的子数组，递归深度 log n，每层 O(n)
- 最好：O(n log n)
- 最坏：O(n²) — 每次分区极度不平衡（如数组已有序且选最左/右当 pivot），递归深度 n
- 空间：O(log n) — 递归栈的深度，最坏 O(n)

**稳定性：不稳定。** 分区时交换可能改变相等元素的相对顺序。

> 💡 **面试高频追问**：快排最坏情况是什么？怎么避免？→ 答：有序数组 + 选端点做 pivot → 三数取中 / 随机化 pivot。

### 3.2 归并排序 (Merge Sort)

**思想**：分治法。把数组从中间分成两半，分别排序，再把两个有序数组合并。

```
                6  2  8  1  4  3  7  5
                   /            \
              6 2 8 1        4 3 7 5
              /   \           /   \
            6 2   8 1      4 3   7 5
            / \    / \     / \    / \
           6   2  8   1   4   3  7   5  ← 拆分到最小
           \ /    \ /     \ /    \ /
           2 6   1 8     3 4   5 7   ← 合并
              \  /          \  /
            1 2 6 8       3 4 5 7
                  \        /
               1 2 3 4 5 6 7 8       ← 最终合并
```

**代码（自顶向下，递归版）：**
```java
public void mergeSort(int[] arr) {
    mergeSort(arr, 0, arr.length - 1, new int[arr.length]);
}
private void mergeSort(int[] arr, int left, int right, int[] temp) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid, temp);       // 左半排序
    mergeSort(arr, mid + 1, right, temp);  // 右半排序
    merge(arr, left, mid, right, temp);    // 合并
}
// 合并两个有序数组：[left, mid] 和 [mid+1, right]
private void merge(int[] arr, int left, int mid, int right, int[] temp) {
    int i = left;    // 左指针
    int j = mid + 1; // 右指针
    int k = left;    // temp 指针
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) { // <= 保证稳定性
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) temp[k++] = arr[i++]; // 左边剩余
    while (j <= right) temp[k++] = arr[j++]; // 右边剩余
    // 拷回原数组
    for (int m = left; m <= right; m++) {
        arr[m] = temp[m];
    }
}
```

**特点：**
- 时间复杂度稳定，**最坏也是 O(n log n)**（不像快排有最坏情况）
- **稳定排序**：合并时左边的相同值先放，保持相对顺序
- 唯一的缺点：**需要 O(n) 的额外空间**（不是原地排序）
- 适合外部排序（数据太大装不下内存时，归并是首选）

**快排 vs 归并：**

| 特性 | 快排 | 归并 |
|------|------|------|
| 平均时间 | O(n log n) | O(n log n) |
| 最坏时间 | O(n²) | O(n log n) |
| 空间 | O(log n) | O(n) |
| 稳定性 | 不稳定 | 稳定 |
| 排序方式 | 原地排序 | 需要额外空间 |
| 实际速度 | 通常更快（常数因子小） | 稍慢（有额外空间开销） |
| 适用场景 | 数组排序（默认首选） | 链表排序、外部排序、需要稳定性 |

### 3.3 堆排序 (Heap Sort)

**思想**：先把数组构建成一个大顶堆，然后不断把堆顶（最大值）和末尾交换，堆大小减 1，再把堆顶下沉维护堆性质。最终数组就从小到大有序了。

**步骤：**
1. 建堆（从最后一个非叶节点开始，向前逐个下沉）
2. 排序（交换堆顶和末尾 → 堆顶下沉 → 重复）

```
初始数组：   6  2  8  1  4  3  7

建大顶堆：    8
           /   \
          4     7
         / \   / \
        1   2 3   6
数组表示：   8  4  7  1  2  3  6

第1轮：堆顶 8 和末尾 6 交换 → 6  4  7  1  2  3 | 8
       对堆顶 6 下沉 → 7  4  6  1  2  3 | 8

第2轮：堆顶 7 和末尾 3 交换 → 3  4  6  1  2 | 7  8
       对堆顶 3 下沉 → 6  4  3  1  2 | 7  8
...
最终：    1  2  3  4  6  7  8
```

**代码：**
```java
public void heapSort(int[] arr) {
    int n = arr.length;
    // 1. 建大顶堆：从最后一个非叶节点开始，向前做下沉
    for (int i = n / 2 - 1; i >= 0; i--) {
        sink(arr, i, n);
    }
    // 2. 排序：不断交换堆顶和末尾，然后堆顶下沉
    for (int end = n - 1; end > 0; end--) {
        swap(arr, 0, end);     // 堆顶（最大）交换到末尾
        sink(arr, 0, end);     // 堆顶下沉（堆大小减为 end）
    }
}
// 下沉操作：大顶堆，size 是当前堆大小
private void sink(int[] arr, int i, int size) {
    while (true) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int largest = i;
        if (left < size && arr[left] > arr[largest]) largest = left;
        if (right < size && arr[right] > arr[largest]) largest = right;
        if (largest == i) break; // 已经是最大，不用下沉了
        swap(arr, i, largest);
        i = largest; // 继续往下
    }
}
```

**复杂度分析：**
- 时间：O(n log n) — 建堆 O(n) + n 次下沉 O(n log n)
- 空间：O(1) — 原地排序
- **不稳定**：建堆和交换过程会改变相等元素的相对顺序

> ⚠️ 易错点：建堆的时间复杂度是 **O(n)**，不是 O(n log n)！因为越靠下的节点越多，但下沉深度越小，总和推导下来是 O(n)。面试被问到"堆排序时间复杂度"时，可以补一句"建堆是 O(n)"会加分。

## 四、线性时间排序（非比较类）

### 4.1 计数排序 (Counting Sort)

**思想**：如果知道数据的范围是 [0, k]，可以用一个计数数组统计每个值出现的次数，然后按顺序输出。

**适用条件**：
- 数据范围不大（k 不大）
- 数据都是整数（或可以映射成整数）

```
数组：     3  1  4  1  5  3  2  4
最大值 5，计数数组大小 6

计数数组： 0  2  1  2  2  1    ← 值为 1 的有 2 个，值为 2 的有 1 个...
           0  1  2  3  4  5

前缀和：   0  2  3  5  7  8    ← 表示"小于等于 i 的数有多少个"
                      ↑
              值为 3 的数放在第 5 位（下标 4）

排序结果： 1  1  2  3  3  4  4  5
```

**代码：**
```java
public void countingSort(int[] arr) {
    if (arr.length <= 1) return;
    // 找最大值
    int max = arr[0];
    for (int num : arr) if (num > max) max = num;
    // 计数数组
    int[] count = new int[max + 1];
    for (int num : arr) count[num]++;
    // 填回去
    int idx = 0;
    for (int i = 0; i <= max; i++) {
        while (count[i] > 0) {
            arr[idx++] = i;
            count[i]--;
        }
    }
}
```

**特点：**
- 时间 O(n + k)，k 是数据范围大小
- 空间 O(k)
- 稳定排序（上面的写法不稳定，改进版用前缀和可以做到稳定）
- k 太大就不划算了（比如数据只有 100 个但范围是 0~1000000）

### 4.2 桶排序 (Bucket Sort)

**思想**：把数据分到多个桶里，每个桶内单独排序（用插入排序/快排等），最后按桶的顺序把数据拿出来。

```
数组：  29  25  3  49  9  37  21  43
范围 0~50，分 5 个桶，每个桶范围 10

桶0(0-9):   3, 9
桶1(10-19): 
桶2(20-29): 29, 25, 21  → 桶内排序 → 21, 25, 29
桶3(30-39): 37
桶4(40-49): 49, 43       → 桶内排序 → 43, 49

按桶的顺序依次取出：3, 9, 21, 25, 29, 37, 43, 49
```

**特点：**
- 时间复杂度：平均 O(n + k)，最坏 O(n²)（所有数据进了同一个桶）
- 空间 O(n + k)
- 稳定排序（桶内排序用稳定算法）
- 关键在于桶的划分：均匀分布时性能好，分布不均时性能差

### 4.3 基数排序 (Radix Sort)

**思想**：按低位到高位（或高位到低位）依次排序，每一轮对某一位用计数排序或桶排序。

```
数组：   170  45  75  90  802  24  2  66

第1轮（按个位排）：
  0位：170, 90
  2位：802, 2
  4位：24
  5位：45, 75
  6位：66
  → 170, 90, 802, 2, 24, 45, 75, 66

第2轮（按十位排）：
  0位：2, 802
  2位：24
  4位：45
  6位：66
  7位：170, 75
  9位：90
  → 2, 802, 24, 45, 66, 170, 75, 90

第3轮（按百位排）：
  0位：2, 24, 45, 66, 75, 90
  1位：170
  8位：802
  → 2, 24, 45, 66, 75, 90, 170, 802  ✓
```

**特点：**
- 时间 O(n × k)，k 是最大位数（数字位数）
- 空间 O(n + k)
- 稳定排序
- 只适用于整数（或可以按位拆分的数据）
- k 太大就不适合了

## 五、排序算法选型与面试要点

### 5.1 怎么选择排序算法？

| 场景 | 推荐排序 | 原因 |
|------|---------|------|
| 一般情况（数组排序） | 快速排序 | 平均最快，常数因子小，原地排序 |
| 需要稳定性 | 归并排序 | O(n log n) 且稳定 |
| 数据量小、基本有序 | 插入排序 | 常数因子小，接近 O(n) |
| 链表排序 | 归并排序 | 链表天然适合归并，不需要额外空间 |
| 整数、范围不大 | 计数排序/基数排序 | 线性时间 |
| 海量数据（外排序） | 多路归并排序 | 数据装不下内存，分块排序后归并 |
| 找 Top K | 堆排序（小顶堆） | 只维护 K 个元素的堆，O(n log K) |

### 5.2 为什么快排最快但 Java 用了 TimSort？

- Arrays.sort() 对基本类型用的是**双轴快排（Dual-Pivot Quicksort）**
- Arrays.sort() 对对象类型用的是 **TimSort**（归并 + 插入排序的混合）
- 原因：对象类型需要**稳定性**，快排不稳定而归并稳定
- TimSort 是 Java 和 Python 的默认排序算法，对实际数据（很多已有序片段）表现非常好

### 5.3 面试高频问题

**Q：快排的最坏情况是什么？怎么优化？**
- 最坏：数组已有序 + 选端点做 pivot → O(n²)
- 优化：三数取中 / 随机化 pivot / 三路快排（重复元素多）

**Q：哪些排序是稳定的？哪些不稳定？**
- 稳定：冒泡、插入、归并、计数、桶、基数
- 不稳定：选择、希尔、快排、堆排
- 记忆技巧：**快选希堆不稳（快、选、希、堆都不稳定）**

**Q：堆排序的建堆时间复杂度？**
- 建堆 O(n)，排序 O(n log n)，总 O(n log n)

**Q：快速排序空间复杂度？**
- 递归栈深度，平均 O(log n)，最坏 O(n)

**Q：冒泡排序最好情况是 O(n) 吗？**
- 是的，加了 swapped 优化后，第一轮没交换就直接结束，O(n)

**Q：快排和归并分别适合什么场景？**
- 快排：数组排序、内存充足、不需要稳定性
- 归并：链表排序、外部排序（数据太大）、需要稳定性
